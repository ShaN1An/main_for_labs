# Менеджер заметок

Консольное приложение на Python для работы с текстовыми заметками.

Программа позволяет добавлять заметки, просматривать их, искать текст, очищать список заметок и получать случайные подсказки.

## Возможности

- добавление новой заметки;
- просмотр всех заметок;
- поиск слова или части текста;
- очистка всех заметок;
- вывод справки по командам;
- случайные подсказки;
- обработка неправильного ввода без аварийного завершения.

## Команды

`add <текст>` — добавить новую заметку.

Пример:

```text
add Купить хлеб
```

`list` — показать все сохранённые заметки.

`find <слово>` — проверить, встречается ли указанное слово или текст в заметках.

Пример:

```text
find хлеб
```

`clear` — удалить все заметки.

`help` — показать список доступных команд.

`tip` — вывести случайную подсказку.

`exit` — завершить программу.

## Структура проекта

```text
project/
├── main.py
├── notes_data.py
└── requirements.txt
```

`main.py` содержит основную логику программы.

`notes_data.py` хранит название приложения, текст справки, разделитель заметок и тексты случайных подсказок.

`requirements.txt` содержит список зависимостей проекта.

## Используемые функции

Основная логика программы разделена на функции:

```python
show_help()
add_note(notes, text, sep=";")
list_notes(notes)
find_note(notes, word)
random_tip()
```

Функция `add_note()` принимает аргумент `sep=";"` по умолчанию. Он используется как разделитель между заметками.

## Хранение заметок

Заметки хранятся в строковой переменной `notes`.

Внутри программы они разделяются символом `;`.

Например:

```text
Купить хлеб;Сделать лабораторную;Позвонить другу
```

При использовании команды `list` программа проходит по строке и выводит каждую заметку отдельно.

## Случайные подсказки

Для команды `tip` используется модуль `random`.

В начале программы установлен фиксированный seed:

```python
random.seed(31)
```

Благодаря этому последовательность случайных подсказок остаётся воспроизводимой при повторных запусках программы.

## Запуск

Для запуска программы необходимо открыть терминал в папке проекта и выполнить:

```bash
python3 main.py
```

```text

Доступные команды:
add <текст> - добавить заметку
list - показать заметки
find <слово> - найти слово
clear - удалить все заметки
help - показать список команд
tip - показать случайную подсказку
exit - выйти

> add Купить хлеб
Заметка добавлена.

> add Сделать лабораторную

Ваши заметки:

Сделать лабораторную

> find хлеб
Найдено.

```

## Ограничения

Заметки хранятся только во время работы программы.

После завершения программы данные не сохраняются, так как файловый ввод-вывод не используется.
